## 2026-07-21 - [Indexing Domain Timestamp Columns for Telemetry, Forecasts, and Alerts]
**Learning:** Default Eloquent `latest()` calls use `created_at` which does not leverage domain-specific indexes on columns such as `recorded_at`, `forecasted_for`, or `triggered_at`. By explicitly creating database indexes on these frequently-queried domain-specific timestamps and specifying them in `.latest('column')` queries, database query performance is improved from a potential table scan to a highly efficient index scan/lookup.
**Action:** When working with telemetry/time-series data, always index the primary event timestamp columns (e.g., `recorded_at`) and make sure all queries ordering or filtering by these timestamps explicitly reference them instead of relying on default `created_at` timestamps.
